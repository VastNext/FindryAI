# 搜索页布局调整设计

## 目标

提升 `/search` 页搜索框的视觉优先级，让用户进入页面后可以立即搜索，同时保留现有筛选和结果功能。

## 布局

页面内容依次为：

1. `Search` 页面标题
2. 参考 `/home2` 样式的居中搜索框
3. 分类、标签、排序等现有筛选控件
4. 搜索结果与分页

删除现有副标题 `Search anything you want`。桌面端搜索框最大宽度约为 640px，移动端占满可用宽度且不产生横向溢出。

## 交互

提交关键词时继续导航到 `/search`，更新 `q` 参数并重置分页。保留当前分类、标签、排序和查询筛选参数，避免用户在细化搜索时丢失已有筛选条件。

## 范围

复用现有设计系统和搜索数据流，不改动结果查询、筛选数据加载、结果卡片或分页逻辑，也不引入新的动画和依赖。

## 验证

- 运行 Biome 只读检查和生产构建。
- 在桌面与移动视口检查标题、搜索框、筛选器和结果区的排列与宽度。
- 验证带已有筛选参数提交关键词后，筛选参数得到保留且页码重置。
