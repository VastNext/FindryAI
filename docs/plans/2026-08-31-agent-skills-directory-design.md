# Agent Skills 目录设计

## 目标

在 FindryAI 新增公开 `/agent-skills` 页面，使用 MOGE 当前公开的 Agent Skills 名称、简介、分类和外链做一版可验收的静态目录，不写入生产 Sanity。

## 产品范围

首版包含：

- 17 个主题与约 278 条公开资源；
- 标题、说明和页面内关键词搜索；
- 桌面粘性分类导航；
- 点击分类平滑滚动；
- 页面滚动时联动高亮当前分类；
- 移动端双列卡片；
- 卡片直接打开 GitHub 或产品官网；
- FindryAI 导航、Footer、Metadata 和 Sitemap 接入。

首版不包含：

- Sanity 数据写入；
- 站内 Skill 详情页；
- 安装命令、GitHub stars、版本与兼容性筛选；
- 用户投稿；
- 分页或加载更多。

## 架构

静态数据保存在 `src/data/agent-skills.ts`，由服务端页面直接下发。交互集中在一个客户端目录组件中，负责关键词过滤、分类滚动与高亮；卡片保持独立、轻量、可访问。页面使用现有 Container、主题变量、Header/Footer 与路由结构，不引入新依赖。

## 视觉设计

延续 FindryAI 的圆角、细边框、主题色和深浅模式。资源卡片不显示 16:9 截图，而是使用统一来源图标、名称和两行说明，以高密度网格呈现；Hover 只改变背景与标题颜色。桌面侧栏提供清晰定位，移动端隐藏侧栏并保留分组标题。

## 数据来源与边界

数据来自 MOGE 页面公开 HTML 中嵌入的目录字段，仅保存名称、短描述、公开外链和分类。去除 MOGE 的 UTM 参数，不复制其站点品牌素材或页面源代码。GitHub 项目使用统一 GitHub 图标，其他项目使用通用链接图标，避免依赖 MOGE 图片 CDN。

## 验收

- `/agent-skills` 可公开访问；
- 数据数量与分组结构完整；
- 搜索可按名称和描述过滤；
- 桌面分类点击和滚动高亮正确；
- 移动端无横向溢出；
- 外链在新标签打开并带安全 rel；
- `pnpm build` 通过；
- Vercel Preview 为 Ready。
