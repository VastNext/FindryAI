# VPS 迁移执行任务包

状态：文档契约 v1；工具尚未实现；生产迁移 **BLOCKED**。本任务包允许规划与派发本地开发，不代表授权连接生产执行写操作、购买服务或创建远程仓库。

## 接手顺序

1. 所有执行者先读本文及 [契约](contracts.md)。协调者为任务分配唯一负责人、工作目录、基线提交及文件白名单。
2. 开发者只读取 [任务卡](tasks.md) 中分配给自己的任务，以及对应的 [测试规范](tests.md)。只在自己隔离工作区编写代码；完成后回交证据，不直接合并或部署。
3. 协调者检查前置任务 PASS、契约版本及文件冲突后才派发下一层。任何必填值缺失标为 BLOCKED，并提出一个明确问题，不自行选值。
4. 集成验收通过后，由唯一生产执行者使用 [生产操作单](runbook.md)。其他代理没有生产密钥，也不运行 SSH、DNS 或控制面写操作。

原设计依据：[总方案](../plans/2026-11-23-001-feat-multi-site-vps-migration-plan.md)。总方案保留背景和取舍；任务顺序、开发接口与放行规则以本任务包为准。用户后续决定需由协调者更新契约版本，重新验证受影响任务后生效。

## 权限与可并发范围

| 角色 | 允许 | 禁止 |
| --- | --- | --- |
| 协调者 | 解析阻塞、分配任务、审查合并、登记验收 | 将文档批准当作生产授权 |
| 开发者 | 独占文件内开发、合成夹具测试、提交交接报告 | 生产密钥、共享主机写操作、修改其他任务文件 |
| 集成验收者 | 在获准的隔离主机验证合并产物 | 用生产数据库或真实收件人代替测试资源 |
| 生产执行者 | 执行匹配授权单的单次变更 | 同时派发第二个生产写执行者 |
| 用户 | 确认成本、环境、生产窗口和风险 | 凭据不通过聊天传递 |

代码可并发；宿主机、Caddy、DNS、生产调度交接串行。CI 运行时并发同样受契约锁约束，不能绕过生产执行者的维护锁。

## 交接格式

每项任务在其分支新增 `handoffs/<task-id>.md`，内容依次为：任务 ID、契约版本、基线与交付提交、修改文件、依赖提交、测试 ID/状态/证据路径、已知阻塞、回退方法。不得附秘密或个人数据。

状态仅允许 `NOT_RUN`、`PASS`、`FAIL`、`BLOCKED`、`N/A`。N/A 必须由协调者写理由并批准，开发者不能自行豁免必测项。只有协调者可将整个任务标记 PASS。

证据存放 `evidence/<run-id>/`（受限存储，不上传含敏感内容的原始日志）；每次记录 UTC 时间、环境 ID、源提交、镜像 digest、配置哈希、夹具版本、退出码与断言。脱敏摘要可提交。工具返回成功但断言不满足仍为 FAIL。

## 现在如何开始

先派发 D00 整理决定表；未批准远程仓库名称时，D02–D04 可在本地独立暂存的基础设施源码目录开发，不能自行创建 GitHub 仓库。D01 在应用仓库独立工作区执行。本地新 worktree 仅能创建在获准的 G 盘根目录中，且须遵循全局路径规则。

此包不包含已可运行的部署脚本。文中 `bin/*` 是待实现的接口，不可复制命令后假称工具已存在。生产命令只有在 D07 生成并验收操作附录后才可执行。
